# 给晴晴 · 不分日子的祝福

一片只属于她一个人的星空。没有节日、没有日子，打开就能看。

线上地址：**https://dll315.github.io/qingqing/**

## 页面里有什么

| 段落 | 内容 |
| --- | --- |
| 首屏 | 一个会呼吸的「晴」字，外面套着缓慢转动的星轨 |
| 这个字 | 拆字：日 + 青 = 晴 —— 日光把天色照得青透，就是晴 |
| 十二个愿 | 祝福卡片墙，鼠标划过会浮起来、背后亮起一团暖光 |
| 还有几句 | 打字机三行剧本，一句句亮起来再退回去，循环播放 |
| 对着这片星空 | 点按钮落流星、随机换一句祝福；直接戳夜空任意位置也会落星 |
| 最后 | 实时时钟「此刻 · X 年 X 月 X 日 星期 X HH:MM」+ 落款 |

许愿次数记在浏览器 `localStorage` 里，她下次打开会接着数。

## 技术

单文件 `index.html`，**零依赖、零构建、零外部请求**（不引 CDN、不加载字体、不发统计）。

- Canvas 星空：三层视差 + 正弦闪烁，星星数量按屏幕面积算（90–240 颗），DPR 上限 2
- 滚动淡入用 `IntersectionObserver`，滚到哪算到哪
- 流星：随机自发 + 点击触发，带渐隐拖尾
- 移动端自适应；`prefers-reduced-motion` 下自动关掉动画
- 字体走系统中文字体栈（宋体系标题 + 苹方/雅黑正文），所以断网也不掉相

## 改文案

全部内容集中在 `index.html` 底部的 `<script>` 里，改完直接提交即可，不用构建：

- `WISHES` —— 十二个愿（卡片标题 + 小字）
- `WHISPERS` —— 打字机的三行剧本，空字符串表示那一行留白
- `SHOTS` —— 点「许一个愿」随机出现的句子
- HTML 里的 `hero` / `etym` / `sign` 段落 —— 首屏、拆字、落款
- 落款 `想一直陪你放晴的人` 换成你自己的署名

## 部署

### GitHub Pages（默认）

仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main` / 根目录。推 `main` 即自动发布。

### 自建（可选）

纯静态，任何静态服务器都能跑：

```bash
docker build -t qingqing .
docker run -d --name qingqing -p 3581:80 qingqing
```

或者不开容器，随便找个静态服务器指向这个目录就行（`index.html` 单文件，没有相对资源）。
